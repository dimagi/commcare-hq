Case Data API v1
================

List cases in a project space, or fetch a single case by identifier.
Cases track structured data about a person, place or thing, collected
and updated by CommCare mobile or web app forms.

The full reference for this API — every endpoint, parameter and response
field — is published at `Case Data API v1
<https://www.commcarehq.org/api/docs/case-v1/>`_.
