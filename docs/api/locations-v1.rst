Location API v1
===============

List locations in a project space, or fetch a single location by
identifier. See `Location API v2
<https://www.commcarehq.org/api/docs/location-v2/>`_ for a newer version
that adds create and update support.

The full reference for this API — every endpoint, parameter and response
field — is published at `Location API v1
<https://www.commcarehq.org/api/docs/location-v1/>`_.
