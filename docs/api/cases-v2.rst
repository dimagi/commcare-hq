Case Data API v2
=================

Fetch, create and update cases in bulk, with JSON payloads and
cursor-based pagination for pulling large datasets. Cases track
structured data about a person, place or thing, collected and updated by
CommCare mobile or web app forms.

The full reference for this API — every endpoint, parameter and response
field — is published at `Case Data API v2
<https://www.commcarehq.org/api/docs/case-v2/>`_.
