Location API v2
===============

List locations in a project space, create locations, or fetch and update
a single location, one at a time or in bulk. Version 2 returns location
data as a nested object and supports filtering by last modified date.

The full reference for this API — every endpoint, parameter and response
field — is published at `Location API v2
<https://www.commcarehq.org/api/docs/location-v2/>`_.
